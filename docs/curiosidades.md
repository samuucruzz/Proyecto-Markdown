# 🤓 Curiosidades del Real Madrid

[⬅️ Volver al README](../README.md "Volver a la página principal")

- El club se fundó el **6 de marzo de 1902** con el nombre de *Madrid Foot Ball Club*.
- El título de **"Real"** se lo concedió el rey Alfonso XIII en **1920**.
- Ganó las **cinco primeras** Copas de Europa seguidas (1956-1960).
- El Santiago Bernabéu acogió la final del **Mundial de 1982** (Italia 3-1 Alemania).
